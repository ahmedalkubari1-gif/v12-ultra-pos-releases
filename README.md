# V12 Ultra POS Releases

This public repository contains release artifacts for V12 Ultra POS applications. It does not contain the application source code.

Artifacts may include:

- Windows Electron installer (`.exe`)
- Electron update metadata (`latest.yml`)
- Electron differential update files (`.blockmap`)
- Android APK files (`.apk`)

The Windows application checks this public release channel for signed, versioned updates. Source code remains in private development repositories.
